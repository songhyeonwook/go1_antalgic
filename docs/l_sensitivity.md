# GT 부목 길이 L 민감도 — teacher 는 L 을 **어디서** 읽는가

- 날짜: 2026-08-24
- 체크포인트: `backup/antalgic_P2/2026_08_16_18_10_21_phase2_s42_P2-splint-004-0815/model_10998.pt`
  (대조: `FT_P2/...fault-tolerant-001`, `SYM_P2/...symmetric-002` — 동일 seed 42)
- 데이터: `test/dumps/p2_pain2_final.npz` (오프라인) / `test/dumps/lsens/*.npz` (폐루프)
- 도구: `test/l_sensitivity.py`, `test/l_sensitivity_report.py`

## 배경

μ 는 antalgic 보행에서 비식별임이 실측되어 privileged 관측에서 제거됐다
(c7bcf79, 근접 슬립 0% + teacher 민감도 ~1%). 같은 질문을 **L** 에 던진다:
teacher 가 받는 GT 부목 길이 `privileged[5]` 는 정책 행동을 실제로 바꾸는가?

μ 때와 동일한 프로토콜 — **물리는 그대로 두고 teacher 입력 채널만 조작**한다.
(물리 부목 길이를 바꾸는 것은 별개 실험이며, 그것은 "환경 변화"지 "정보 이용"이 아니다.)

## 방법

**[A] 오프라인 재생** — `analyze_student.py` [S0] 규약(`a_replay[t] ↔ action[t+1]`)
으로 덤프된 obs 를 teacher MLP 에 재생. 재생 검증 |Δa| max = 1.9e-6 (OK).
teacher 는 feed-forward 라 hidden state 가 없어 정확히 일치해야 한다.

**[B] 폐루프 롤아웃** — `rollout_dump.py --l_obs_fixed X` 로 **부상 env 의**
L 채널만 X 로 고정한 채 40 env × 1500 step (seed 42, balanced) 재실행.
`gt_L` 중앙값이 전 조건 0.390 으로 동일함을 확인 — 물리는 무손상.

## 결과 [C] — 결정적 대조: 같은 길이 정보를 RLS 채널로 흔들면?

⚠️ teacher 는 `obs_groups` 상 **policy 그룹도 함께 받는다** — 즉 RLS 추정
`[L̂_norm, √P_norm]`(policy[49:51])을 privileged GT L 과 **동시에** 보고 있다.
따라서 [A]/[B] 의 무반응만으로는 "길이가 무용"인지 "중복이라 무시"인지 갈리지
않는다. 같은 물리 범위를 RLS 채널로 흔들어 비교한다:

| 흔든 채널 | 물리적으로 같은 범위 | mean\|Δa\| | /std |
|---|---|---|---|
| **RLS L̂ (policy[49])** | 0.33 → 0.45 m | **0.2803** | **16.2%** |
| RLS √P (policy[50]) | 확신 → prior | 0.0815 | 4.7% |
| GT L (privileged[5]) | 0.33 → 0.45 m | 0.0066 | 0.4% |
| μ (privileged[6]) | 0.5 → 1.5 | 0.0254 | 1.5% |
| RLS 채널 차단(prior 고정) | — | 0.1123 | 6.5% (정상 env 0.3%) |

섭동 범위 타당성: 덤프 내 실측 L̂ 은 p5–p95 = [0.335, 0.445] m 로, 흔든 폭이
실제 분포 폭과 일치한다(인위적 외삽 아님).

## 해석

1. **teacher 는 부목 길이를 쓴다 — 단지 GT 가 아니라 RLS 추정에서 읽는다.**
   같은 물리 범위인데 RLS L̂ 은 16.2%, privileged GT L 은 0.4% — **40배 차이**다.
   RLS 채널 쪽은 대조군 lin_vel_y(11.8%)보다도 크다. 즉 GT L 채널은 **무용이
   아니라 중복**(redundant)이며, [A]/[B] 의 평탄함은 "길이 정보가 불필요하다"가
   아니라 "이미 policy 그룹에서 같은 정보를 받고 있다"는 뜻이다.
2. **RLS 채널 이용은 부상 조건부다.** 채널 차단 시 부상 env 6.5% vs 정상 env
   0.3% — 부상일 때만 반응하는 구조적 서명. 반면 GT L 은 부상(0.4%)/정상(0.3%)
   이 같아 조건화 흔적이 없다.
3. **불확실도 √P 도 쓰인다** (4.7%). 정책이 추정값뿐 아니라 그 신뢰도에도
   조건화되어 있다 — 배포 시 √P 게이팅 권고(`ablation_rls_lstm.md`)와 정합.
4. **μ 제거의 근거는 L 로 이전되지 않는다.** μ 는 policy 그룹에 대응 채널이
   없어 privileged 무반응이 곧 "정보 미사용"이었다. L 은 policy 그룹에 대체
   경로(RLS)가 있으므로 같은 논리를 적용할 수 없다.
5. **하중 재분배**: duty·접지력이 GT L 에 평탄한 것은 맞지만(1 과 같은 이유),
   폐루프에서 RLS 채널을 흔든 실험은 아직 하지 않았다 — 아래 "미결" 참고.

## 이 결과로 말할 수 있는 것 / 없는 것

| 주장 | 근거 |
|---|---|

| ✅ teacher 정책은 부목 길이 정보에 강하게 조건화됨 | [C]: RLS L̂ 16.2%, 부상 조건부 |
| ❌ "길이 추정 자체가 불필요" | **반증됨** — 추정 채널이 GT 보다 40배 영향이 크다 |
| ❓ 추정 *정확도*(mm급)가 성능에 필요한가 | 미검증 — 폐루프 L̂ 섭동 실험 필요 |
